# Artwork provenance

Sprites generated using the built-in imagegen tool. Prompt: “Create a production sprite atlas for a desktop pet using these two reference images of the same yellow chubby green-eyed dinosaur Nailong. Faithful soft 3D rendering, cream belly, brown fingertips/toes. Transparent background. Exactly 4 equal square cells in ONE horizontal row, overall 4:1 ratio. Each full body centered with generous clear padding, same scale, feet same baseline. Cell 1: front-facing idle standing arms crossed like reference 1, full feet visible. Cell 2: running facing RIGHT like reference 2, left leg forward right leg back. Cell 3: running facing RIGHT opposite stride right leg forward left leg back, arms opposite. Cell 4: standing three-quarter facing RIGHT, right arm extended with index finger pointing horizontally to RIGHT at mid-height. No text, no borders, no ground, no shadow outside character. Each cell isolated, no overlap.”

The generated running poses are similar; the prototype alternates them with a bounce, rather than a full articulated run cycle. Extend the atlas and animation for smoother production motion.
