# AI-generated artwork

The Nailong sprite atlas in `Assets/nailong-atlas.png` was generated entirely with OpenAI's image generation tool. No manually drawn or photographic image layers were added to the sprite atlas. The prompts described Nailong's appearance and poses, using supplied visual references as guidance for the generated result.

The sprite atlas is included under the project MIT License, with permission from the project owner. The MIT license text in [LICENSE](LICENSE) explicitly includes the source, documentation and included AI-generated artwork. The running poses are similar; the prototype alternates them with a bounce rather than a fully articulated run cycle.

## Generation prompt

“Create a production sprite atlas for a desktop pet using these two reference images of the same yellow chubby green-eyed dinosaur Nailong. Faithful soft 3D rendering, cream belly, brown fingertips/toes. Transparent background. Exactly 4 equal square cells in ONE horizontal row, overall 4:1 ratio. Each full body centered with generous clear padding, same scale, feet same baseline. Cell 1: front-facing idle standing arms crossed like reference 1, full feet visible. Cell 2: running facing RIGHT like reference 2, left leg forward right leg back. Cell 3: running facing RIGHT opposite stride right leg forward left leg back, arms opposite. Cell 4: standing three-quarter facing RIGHT, right arm extended with index finger pointing horizontally to RIGHT at mid-height. No text, no borders, no ground, no shadow outside character. Each cell isolated, no overlap.”
